Export all data

Downloads every record saved in this browser as one JSON file. The file is made on your computer and is not sent anywhere.

Before you share the file:
  • On GitHub Pages, other projects under the same account share this storage, so their records appear in the file too (marked "Other" below).
  • It includes the fake staff accounts: password hashes, salts and the secrets behind the one-time codes. Keep an export private if you ever use real data.
